# Deriv Pro Analyser

A live market-data analysis dashboard built with React, TypeScript, Vite, Tailwind CSS, and Recharts.

## Features
- Connects to Deriv public WebSocket
- Discovers active / volatility-like markets
- Fetches historical ticks
- Subscribes to live tick updates
- Extracts last digits from each quote
- Builds digit frequency and distributions
- Shows live matches, even/odd, over/under analysis
- Includes volatility scanner and frequency graph
- Mobile-first responsive dashboard

## Installation

npm install

## Run locally

npm run dev

## Production build

npm run build
